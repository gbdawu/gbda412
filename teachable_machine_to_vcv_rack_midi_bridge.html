How to Route MIDI to VCV Rack

Web MIDI sends control signals directly into your operating system's virtual MIDI loopback cables. Follow your OS instructions below:

Windows

Install free loopMIDI. Create a virtual port named TeachableMIDI.

macOS

Open Audio MIDI Setup ➔ Show MIDI Studio ➔ Double-click IAC Driver ➔ Check "Device is online".

Linux

Enable snd-virmidi kernel module or use JACK MIDI connections.

Connecting inside VCV Rack:

  1. Add a MIDI-CV or MIDI-CC module from VCV Core to your rack.
  2. Set Driver to Windows MIDI / ALSA / CoreMIDI.
  3. Select your Virtual Port name (loopMIDI / IAC Driver) from the device list.
  4. Patch the CV / CC / GATE outputs directly into VCO pitch, VCF filters, or envelope triggers!
